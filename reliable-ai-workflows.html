Evalueserve / WORKFLOW INFRASTRUCTURE

Making AI workflows resumable.

Separating background execution from API serving, preserving progress, and bringing people into the loop.

Simplified conceptual flow. Describes the implementation approach, not a complete production topology.

01

The constraint

The agentic studio ran with Uvicorn workers, each loading its own copy of the service and its dependencies. Long-running AI execution needed a separate lifecycle, alongside a way to preserve progress and pause for human decisions.

02

What I owned

I built the React execution and status views and human approval interfaces, alongside the Celery worker migration, checkpointing, and human-in-the-loop mechanisms. I also contributed ingestion pipelines and guardrails to the context infrastructure. Prometheus observability was part of the broader team effort.

03

Separate execution from serving

We moved background execution into Celery workers so those workers could load the components needed for a job without spawning the complete API service. This separated request handling from background processing and gave task processes a more focused execution lifecycle.

04

Preserve progress across pauses

Checkpoints were initially stored in Redis and later moved to a database. A workflow could pause for human approval and resume from its saved checkpoint after approval, carrying forward its execution context.

05

Make execution visible

I built execution and status views so users could follow workflow progress, along with the human approval interfaces used to review and approve paused workflows. This connected the user-facing experience with the checkpoint and resume mechanisms I worked on in the backend.

06

Context with boundaries

My work on ingestion pipelines and guardrails supported the context supplied to AI workflows. These controls helped reduce hallucination risk; they were not a guarantee of factual correctness.

07

Outcome and measurement

The platform gained background task execution, saved progress, and human approval flows. Memory improvements were not measured, so no numerical memory reduction is claimed.
